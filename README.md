# 自己紹介ページ & 学習メモアプリ

## 概要

このプロジェクトは、HTML・CSS・JavaScriptの基礎を学ぶために作成した自己紹介ページです。

最初はシンプルな自己紹介ページから始め、CSSでデザインを追加し、JavaScriptでメモを追加・完了・削除できる機能を実装しました。

## 作った目的

PC初心者の状態から、Codexを使いながらWeb制作とJavaScriptの基礎を学ぶために作成しました。

## 使用した技術

- HTML
- CSS
- JavaScript
- Git
- GitHub

## 主な機能

- 自己紹介ページの表示
- プロフィール欄の表示
- 学習記録の表示
- 学習メモの追加
- Enterキーでメモを追加
- メモをクリックして完了済みにする
- 削除ボタンでメモを削除

## 学んだこと

- HTMLでページの中身を作る方法
- CSSで見た目を整える方法
- JavaScriptでボタンや入力欄を操作する方法
- Gitで作業履歴を保存する方法
- GitHubにコードをアップロードする方法

## 今後追加したい機能

- 入力したメモをブラウザに保存する機能
- ページのデザイン改善
- スマホでも見やすいレイアウト
- 作ったページをWeb上で公開する
