# 学習メモアプリ

## 概要

このアプリは、HTML・CSS・JavaScriptの基礎学習として作成した学習メモアプリです。

メモの追加、編集、削除、完了済みの切り替え、検索、件数表示、作成日表示、ブラウザ保存に対応しています。

PC初心者の状態から、Codexを使いながらWeb制作とJavaScriptの基本を学ぶために作成しました。

---

ここにGitHub PagesのURLを貼ります。

---

## 主な機能

- メモを追加できる
- Enterキーでもメモを追加できる
- メモを編集できる
- メモを1つずつ削除できる
- メモをすべて削除できる
- メモをクリックして完了済みにできる
- 「すべて」「未完了」「完了済み」で表示を切り替えられる
- メモを検索できる
- 合計・完了・未完了の件数を表示できる
- 作成日を表示できる
- ブラウザを更新してもメモが残る
- スマホでも見やすいデザイン
