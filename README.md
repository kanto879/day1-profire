# 学習メモ・タスク管理アプリ

## 概要

このアプリは、HTML・CSS・JavaScriptの基礎学習として作成した、学習メモ兼タスク管理アプリです。

メモの追加、編集、削除、完了管理、検索、フィルター、優先度、期限日、期限切れ表示、ブラウザ保存に対応しています。

PC初心者の状態から、Codexを使いながらWeb制作とJavaScriptの基本を学ぶために作成しました。

## 主な機能

### メモ管理

- メモを追加できる
- Enterキーでもメモを追加できる
- メモを編集できる
- メモを1つずつ削除できる
- メモをすべて削除できる
- メモをクリックして完了済みにできる
- メモがないときに案内メッセージを表示できる

### 件数表示

- 合計件数を表示できる
- 完了件数を表示できる
- 未完了件数を表示できる

### 日付管理

- 作成日を表示できる
- 期限日を設定できる
- 期限なしのメモも作成できる
- 期限切れを表示できる
- 今日が期限のメモを表示できる
- 明日が期限のメモを表示できる
- 期限が近いメモを表示できる

### 優先度管理

- 優先度を「高・中・低」から選べる
- 優先度をメモに表示できる
- 優先度ごとに見た目を変えられる
- 優先度順に並び替えできる

### 検索・フィルター

- キーワードでメモを検索できる
- 「すべて」「未完了」「完了済み」で表示を切り替えられる
- 「期限すべて」「期限切れ」「期限あり」「期限なし」で表示を切り替えられる
- 「優先度すべて」「高」「中」「低」で表示を切り替えられる
- 検索、完了フィルター、期限フィルター、優先度フィルターを組み合わせて使える

### 保存・表示

- localStorageを使ってブラウザにデータを保存できる
- ページを更新してもメモが残る
- スマホでも見やすいレスポンシブデザイン
- GitHub PagesでWeb上に公開できる
